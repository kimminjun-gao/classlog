클래스로그

진도와 아이들의 수업태도를
쉽고 간단하게 기록하는 선생님 앱

⚠️ 아직 웹 앱 주소가 연결되지 않았어요.
index.html 위쪽의 APP_URL에 Apps Script 웹 앱 URL(…/exec)을 넣어 주세요.
✅ 설치되었어요! 홈 화면(또는 바탕화면)의 클래스로그 아이콘으로 실행하세요.

📱 iPhone · iPad에 설치하기

  1. Safari로 이 페이지를 열어 주세요.
  2. 아래쪽(아이패드는 위쪽)의 공유 버튼 을 누르세요.
  3. 메뉴를 내려 홈 화면에 추가를 누르세요.
  4. 오른쪽 위 추가를 누르면 끝!

💻 설치 버튼이 안 보이나요?

  1. Android 크롬: 오른쪽 위 ⋮ → 앱 설치 또는 홈 화면에 추가
  2. PC 크롬: 주소창 오른쪽의 설치 아이콘(⊕) 클릭, 또는 ⋮ → 전송, 저장, 공유 → 페이지를 앱으로 설치
  3. PC 엣지: ⋯ → 앱 → 이 사이트를 앱으로 설치
  4. 삼성 인터넷: ≡ → 현재 페이지 추가 → 홈 화면
🌐 설치하지 않고 웹에서 바로 열기

설치해도 기록은 선생님의 구글 스프레드시트에 저장돼요.
처음 실행할 때 구글 계정 로그인과 권한 승인이 필요할 수 있어요.
